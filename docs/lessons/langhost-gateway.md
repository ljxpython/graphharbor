# ASGI 网关与协议层经验库 (langhost-gateway.md)

> 适用于 `libs/langhost/`、Core REST API、SSE 流式长连接、心跳保活与鉴权路由场景。

---

## [坑] Resume 时清除旧 Run 续传标志导致重播丢失状态
- **场景：** 审批中断后调用 `input.respond` 恢复执行，客户端随后拉取 `/threads/{id}/stream/events`
- **错误：** 在命令处理中将旧 Run 的 `stream_resumable` 篡改为 False，导致重放过滤器将其 values 事件丢弃
- **正确：** 严禁篡改已落库 Run 的续传标志，僵尸中断过滤仅针对未消费的 `input.requested`，新 Run 继承配置
- **日期：** 2026-09-30

## [坑] 生产反向代理 45 秒超时切断 SSE 流
- **场景：** 大模型深度思考或复杂工具长时间执行（> 45 秒无数据输出）
- **错误：** 仅依赖模型产出的 token 事件，没有流式定时心跳，被 Nginx/Ingress 判定为死连接强行切断
- **正确：** 网关层必须内置定时注入 15 秒保活心跳帧（ping），保持连接活跃，并在断线时支持 `Last-Event-ID` 续传
- **日期：** 2026-09-27

## [坑] 前端审批中断重放导致历史重复死锁
- **场景：** HITL (Human-in-the-loop) 审批流重连或历史回放
- **错误：** 历史事件全量重放未标记中断已决状态，导致前端误判“审批请求已变化”陷入死锁
- **正确：** 响应帧中区分历史已决中断与当前活动中断，前端维护 `resolvedReviewIds` 响应式过滤网
- **日期：** 2026-09-27
