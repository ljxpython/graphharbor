# AI 工作流与工程规范经验库 (ai-workflow.md)

> 适用于测试执行、双包版本锁步发布、文档体系维护与 AI Harness 本身演进场景。

---

## [坑] 未核实环境直接运行 scripts/test.sh 导致测试库清空
- **场景：** 自动化回归验证或本地执行端到端检查
- **错误：** 在包含已有重要数据的开发库中直接运行 `./scripts/test.sh`，表被全部 DROP 清空
- **正确：** 必须在隔离的、完全可丢弃的独立本地测试数据库环境中执行，运行前核查连接串
- **日期：** 2026-09-25

## [坑] 双包单方升级版本导致 PyPI 依赖解析死锁
- **场景：** 修复单一包内部 bug 并执行发布
- **错误：** 仅提升 `graphharbor` 或 `graphharbor-runtime` 单方版本号，导致另一个包的锁步依赖无法解析
- **正确：** 双包版本必须严格锁步发布，发布前运行 `python3 scripts/check_versions.py` 强制校验
- **日期：** 2026-09-26

## [坑] 文档存在已过时的假目录路径导致开发者误判
- **场景：** 梳理历史 README 与指南文档
- **错误：** 原地保留已废弃的旧路径（如不存在的 `libs/graphharbor/`），读者按图索骥找不到文件
- **正确：** 移动文件后在旧路径设置显式重定向垫片，同时全仓 grep 同步修正有效引用
- **日期：** 2026-09-30
